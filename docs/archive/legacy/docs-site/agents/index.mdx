An AI agent should be able to use SBX without reading the sbx-browser source
repository. Start with these public resources:

| Resource | Purpose |
| --- | --- |
| [/agents/guide/](/agents/guide/) | Deterministic Task → PR → Review → Merge sequence |
| [/llms.txt](/llms.txt) | Compact documentation map |
| [/llms-full.txt](/llms-full.txt) | Concatenated high-value public docs for one-shot context |
| [/openapi.json](/openapi.json) | Build-time public `/v1` OpenAPI 3.1 contract |
| `GET {SBX_BASE_URL}/v1/openapi.json` | Contract served by the actual deployment |
| [/reference/errors/](/reference/errors/) | Canonical error codes and retry hints |

## Agent rules

1. Prefer the high-level Task API/SDK.
2. Preflight repository/delivery capability before committing expensive work.
3. Use durable task/run/revision state as the source of truth after a timeout.
4. Never invent undocumented endpoints from naming patterns.
5. Do not bypass review/merge gates when the product reports a stale or
   non-independent review.
6. Treat provider/account/GitHub failures as integrations to repair, not as
   reasons to rewrite the requested task silently.
