## Defects found and fixed

1. **`ModalPlane` reported "empty" for "couldn't check" — `sbx uninstall`
   exited 0 claiming zero leftovers while never reaching Modal.**
   `list_sandboxes` swallowed *every* `App.lookup` exception (including
   `AuthError`), `_apps` swallowed `modal_cli_failed` (so `stop_app`/`app_url`
   reported "not running"/`None`), and `has_dict`/`delete_dict` flattened
   all errors to `False`. In an unauthenticated clean env `sbx uninstall`
   printed `terminated 0 sandbox(es)` + `app was not running` and exited 0 —
   the exact silent compute leak the module docstring forbids, and a
   violation of the `Plane` contract the tests' `FakePlane` already encodes
   (raise `BootstrapError` on failure). Now: only a genuine
   `NotFoundError` maps to empty; everything else raises `BootstrapError`
   (`sandbox_list_failed` / `modal_dict_failed`); `delete_dict` is
   check-then-act like `delete_secret`; `_apps` propagates CLI failures.
   Verified live: `sbx uninstall` now exits 1 with
   `error[sandbox_list_failed]` when unauthenticated.
   Regression tests: `test_list_sandboxes_{empty_when_app_missing,
   lookup_failure_is_loud,list_failure_is_loud}`,
   `test_stop_app_list_failure_is_loud`, `test_app_url_list_failure_is_loud`,
   `test_has_dict_list_failure_is_loud`,
   `test_delete_dict_{absent_returns_false,failure_is_loud}`,
   `test_uninstall_fails_loudly_when_sandbox_list_breaks`.

2. **`modal app stop` prompts for interactive confirmation — `sbx
   uninstall` could never stop the app.** The authenticated smoke hit
   `Are you sure you want to stop App '…'? [y/N] … no interactive
   terminal detected. Rerun with --yes (-y)` → `modal_cli_failed`.
   `stop_app` now passes `--yes`; argv pinned in
   `test_stop_app_only_stops_deployed`.
