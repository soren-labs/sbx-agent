---
title: Minimum setup
---
Sign in with verified email/password. Add and validate three manual Connections: Modal Token ID/Secret, GitHub token and OpenCode Zen API key. The Console prefers free models in the selected Connection's fresh catalog; discovery alone is not proof of successful inference.

Create a Project with a GitHub repository and immutable environment declaration. Create a Session, choose its three Connections and OpenCode model, and submit a coding request. The request is committed before provisioning. Send follow-ups to the same Session; native CLI context remains pinned.

Capture an immutable ChangeSet after the Turn finishes. Spawn an independent child review/test against that exact subject. Request Delivery to create a draft PR. Merge is a separate command with exact-head, subject, result and policy checks; a Console badge cannot authorize it.
