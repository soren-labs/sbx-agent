title: SBX Browser
---
SBX runs official coding CLIs in user-owned Executors and keeps durable Session identity, conversation and immutable changes in the control plane.

Start with [the four-credential setup](/setup/). Learn [the unified concepts](/concepts/) and [operation/recovery rules](/operations/). The unified business API is under `/api`; API reference is generated from the same typed contract as the server.

No Codex or ChatGPT login is required. OpenCode Zen is the experimental MVP Harness. Modal, GitHub and Zen credentials are entered manually through Connections and stored encrypted. No provider credential is read from the host automatically.
