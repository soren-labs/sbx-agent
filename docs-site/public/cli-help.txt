    sessions            durable Sessions
    execute             create/continue a Session and follow the Turn
    serve               run a local control plane in the foreground (operator)
    migrate             apply database migrations (operator tool)
    server              set up and run a self-hosted control plane in the
                        background (operator)

  --base-url BASE_URL   API base URL (env SBX_BASE_URL)

===== sbx slots =====
usage: sbx slots [-h]
                 {list,providers,add,login,verify,wait,code,show,models,cancel-login,logout,rename,delete}
                 ...

Machine Slots: independent official subscription logins kept on private Modal
Volumes. Exit codes: 0 ok, 1 API error, 2 slot not ready, 3 still pending.

positional arguments:
  {list,providers,add,login,verify,wait,code,show,models,cancel-login,logout,rename,delete}
    list                slots, counts and providers
    providers           subscription providers this deployment offers
    add                 create a slot and start its official login
    login               run the official login again
    verify              re-check the login and refresh the model catalog
    wait                wait until no login is pending
    code                send the code the browser showed after sign-in
                        (Antigravity)
    show                one slot
    models              model catalog and per-model reasoning efforts, with
                        their source
    cancel-login        stop the pending login
    logout              destroy the stored login; the slot stays
    rename              change the label or the account alias
    delete              delete the slot and its volume

options:
  -h, --help            show this help message and exit

===== sbx server =====
usage: sbx server [-h] {init,check,start,restart,stop,status,logs,outbox} ...

Self-hosted control plane lifecycle. Output is JSON. Exit codes: 0 ok, 3
configuration, 4 unreachable/not running, 5 database authentication, 6 no
usable executor (check only).

positional arguments:
  {init,check,start,restart,stop,status,logs,outbox}
    init                create a private server config with fresh keys and a
                        private PostgreSQL
    check               check configuration, PostgreSQL and executors
    start               start the control plane in the background and wait
                        until ready
    restart             stop, then start; durable state is kept in PostgreSQL
    stop                stop the control plane (and the managed PostgreSQL)
    status              process, health and readiness of this instance
    logs                last lines of the server log
    outbox              latest email in the local outbox (verification links
                        without Resend)

options:
  -h, --help            show this help message and exit
